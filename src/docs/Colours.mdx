# Colours

Use these through Tailwind classes, e.g. `bg-primary`, `text-secondary-700`, `border-line`, `bg-surface`.

For small text in a colour, use a deep step (700) so it stays readable. The base red and indigo are for fills, icons and large type.

## Radius

| Token | Value | Class | Used for |
| --- | --- | --- | --- |
| pill | 999px | `rounded-full` | Buttons, tags, nav bar, option pills |
| input | 14px | `rounded-[14px]` | Text fields |
| bubble | 18px | `rounded-bubble` | Chat bubbles |
| tile | 24px | `rounded-tile` | Small cards, review cards, process steps |
| card | 28px | `rounded-card` | Service groups, forms, mobile menu |
| panel | 32px | `rounded-panel` | Case studies, dark panel, closing banner |
