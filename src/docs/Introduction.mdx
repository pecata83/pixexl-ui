# @pixexl/ui

React components and a Tailwind CSS v4 theme for Pixexl projects.

The look is calm and rounded: a paper-coloured ground, thin 1px borders, pill buttons and 24 to 32px card corners. Type is Geist, with Geist Mono for small uppercase labels, numbers and tags.

## Two colours, two jobs

- **Primary red** is for the main action on a page (Book a call), selected states in forms, and the closing banner.
- **Secondary indigo** marks anything AI-related: section kickers, tags, chat bubbles and the dark panel.

Everything else is ink on paper. If you are unsure, leave colour out.

## Writing

Copy is plain and friendly, written like a person talking. AI is described as something that helps a team, never as something that replaces people.

## Install

```bash
npm i @pixexl/ui geist
```

```css
/* app/globals.css */
@import "tailwindcss";
@import "@pixexl/ui/theme.css";
```
